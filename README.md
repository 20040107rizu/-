# バスターズ（プロトタイプ）

スマホの横持ちで遊ぶ、最大4人のオンライン協力ゲームです。ブラウザだけで動きます。

妖怪になって鬼の世界の街に入り込み、見回り鬼に見つからないように鬼玉を集めます。
制限時間内に、マップのどこかにある襖から脱出できれば、集めた鬼玉の数に応じた鬼ガチャが引けます。

## 起動

```bash
npm install
npm start          # http://localhost:3000
```

## 遊び方

1. 名前を入れて「ルームを作る」。4文字のコード（または招待リンク）を仲間に送る
2. ロビーで連れていくお友達（妖怪）を選び、ホストが「鬼の世界へ！」
3. 鬼玉を集めて、制限時間（3分）内に襖から脱出する

| 操作 | スマホ | PC |
|---|---|---|
| 移動 | 画面左側をドラッグ | WASD / 矢印 |
| 攻撃（近くの鬼を自動で狙う） | 攻撃ボタン | J / Space |
| 強攻撃（妖怪のタイプごとに違う） | 強攻撃ボタン | K |
| アイテムを使う | アイテムボタン | L |
| ダッシュ（押している間） | ダッシュボタン | Shift |

### 鬼の世界のルール

- **見回り鬼**：視界（黄色い扇形）に入ると見つかる。見つけた見回り鬼は笛を吹きながら追いかけてくる（攻撃はしない）
- 見つかると**ボス鬼に居場所が報告され**、ボス鬼がまっすぐ向かってくる
- **見回り鬼を倒すと伝達が途切れる**。建物の陰に隠れて振り切っても、しばらくすると諦める
- **ボス鬼**：自分の目で見つけた相手には、赤い予兆エリアのあとに攻撃してくる
- 倒れた仲間の近くに3秒立つと復活させられる
- 左上のミニマップで、見回り鬼（青、見つかったら赤く点滅）、ボス鬼（赤）、アイテム（？）、襖（黄色）が見える。アイテムは近づくまで種類がわからない

### アイテム（1個まで持てる）

| アイテム | 効果 |
|---|---|
| ⚡ 電気トラップ | 足元に設置。ボス鬼が踏むと一定時間しびれる |
| 💣 爆弾 | 設置して3秒後に爆発。鬼に大ダメージ。範囲内の自分や仲間もダメージを受ける |
| 🤖 ロボットパンチ | 前方にパンチを飛ばし、鬼に中ダメージ |
| 🥤 スタミナム | 一定時間ダッシュし放題 |
| 🍙 おにぎり | HP全回復 |
| 👻 ジミーフィールド | 一定時間姿を消す。鬼に見つからず、追跡も切れる |

### 鬼ガチャ

脱出に成功した人だけが引けます。自分が集めた鬼玉の数でガチャ玉の色が決まります。

| 鬼玉 | ガチャ玉 | 出る妖怪 |
|---|---|---|
| 0〜7 | 緑 | Cランク |
| 8〜14 | 青 | Bランク |
| 15〜22 | 赤 | Aランク |
| 23〜31 | 金 | Aランク（60%）かSランク（40%） |
| 32〜 | 黒 | Sランク |

出た妖怪はお友達になり、次からロビーで選べます。高ランクほどHP・攻撃力・速さが上がります。
お友達のデータはその端末のブラウザに保存されます。

### 妖怪のタイプ

| タイプ | 特徴 | 強攻撃 |
|---|---|---|
| ファイター | 近接・高火力 | ダッシュ斬り（無敵） |
| タンク | 高HP | じしん（周りにダメージ＋被ダメ軽減） |
| ヒーラー | 弾が味方に当たると回復 | 回復エリア |
| レンジャー | 遠距離射撃 | 3連ショット |

## 構成

- `server.js`：HTTP配信＋WebSocket。ルーム管理とゲームの計算はすべてサーバー側（1秒に30回計算、15回配信）。見回り鬼とボス鬼は道を探して（A*経路探索）追いかける
- `public/shared.js`：妖怪・アイテム・ガチャ玉のデータと、街の生成・当たり判定（サーバーとブラウザで共通）
- `public/game.js`：Canvas描画、ミニマップ、仮想スティック、ガチャ演出
- `public/index.html`, `style.css`：タイトル／ロビー／ガチャ／リザルト画面

テスト用の環境変数：`TIME_LIMIT`（制限時間を秒で変更）、`TEST_FUSUMA_NEAR=1`（襖を出発地点に置く）
