# オニバスターズ（プロトタイプ）

スマホの横持ちで遊ぶ、最大4人のオンライン協力ボスバトルです。ブラウザだけで動きます。

## 起動

```bash
npm install
npm start          # http://localhost:3000
```

同じWi-Fiのスマホから `http://<PCのIPアドレス>:3000` を開けば遊べます。

## 遊び方

1. 名前とロールを選んで「ルームを作る」
2. 表示された4文字のコード（または招待リンク）を仲間に送る
3. ホストが「バトル開始！」

| 操作 | スマホ | PC |
|---|---|---|
| 移動 | 画面左側をドラッグ | WASD / 矢印 |
| 攻撃（自動で敵を狙う） | 攻撃ボタン長押し | J / Space |
| スキル | スキルボタン | K |
| 必殺技（ゲージ満タン時） | 必殺ボタン | L |

- 赤いエリアはボスの攻撃予兆。光り切る前に避ける
- 倒れた仲間の近くに3秒立つと復活させられる
- ボスはHP35%以下で怒り状態になり、攻撃が速くなる

## ロール

| ロール | 特徴 | スキル | 必殺技 |
|---|---|---|---|
| ファイター | 近接・高火力 | ダッシュ斬り（無敵） | 周囲に大ダメージ |
| タンク | 高HP | 挑発＋被ダメ軽減 | 全員にシールド |
| ヒーラー | 弾が味方に当たると回復 | 回復エリア | 全員全回復・復活 |
| レンジャー | 遠距離射撃 | 3方向ショット | 全方位乱射 |

## 構成

- `server.js` — HTTP配信 + WebSocket。ルーム管理とゲームロジックはすべてサーバー側（30Hzで計算、15Hzで状態配信）
- `public/game.js` — Canvas描画、仮想スティック、入力送信、補間・自キャラ予測
- `public/index.html`, `style.css` — タイトル / ロビー / リザルト画面

## ネットに公開する（Render・無料）

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/20040107rizu/-)

1. 上のボタンを押し、GitHubアカウントでRenderにログイン
2. リポジトリへのアクセスを許可し、「Apply」（`render.yaml` の設定が自動で使われます）
3. 数分で `https://oni-busters-xxxx.onrender.com` のようなURLが発行されるので、仲間に共有

無料プランは15分アクセスがないとスリープし、次の最初のアクセス時は起動に1分ほどかかります。
