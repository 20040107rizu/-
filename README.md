# 鬼バスターズ（プロトタイプ）

スマホの横持ちで遊ぶ、最大4人のオンライン協力ゲームです。ブラウザだけで動きます。

妖怪になって鬼の世界の街に入り込み、見回り鬼に見つからないように鬼玉を集めます。
制限時間内に、マップのどこかにある襖から脱出できれば、集めた鬼玉の数に応じた鬼ガチャが引けます。

## 起動

```bash
npm install
npm start          # http://localhost:3000
```

## 遊び方

1. 名前を入れて「ルームを作る」。4文字のコード（または招待リンク）を仲間に送る
2. ロビーで連れていくお友達（妖怪）を選び、ホストが「鬼の世界へ！」
3. 鬼玉を集めて、制限時間（5分）内に襖から脱出する

| 操作 | スマホ | PC |
|---|---|---|
| 移動 | 画面左側をドラッグ | WASD / 矢印 |
| 攻撃（近くの鬼を自動で狙う） | 攻撃ボタン | J / Space |
| 強攻撃（妖怪のタイプごとに違う） | 強攻撃ボタン | K |
| アイテムを使う | アイテムボタン | L |
| ダッシュ（押している間） | ダッシュボタン | Shift |
| 襖から脱出 | 襖の前で攻撃ボタンを1.5秒長押し | J 長押し |

### 開始とBGM

- 開始すると、ボス鬼が空から街に降ってくる映像が流れ、そのあと5秒のカウントダウンでスタート（この間は時間が減らない）
- BGMはタイトル・ロビー・結果画面の曲（最初に画面に触れると流れ始める）、ふだんの曲、ボス鬼に追われているときの曲（見失って2.5秒で元に戻る）。タイトル画面の「🔊 BGM」でON/OFF（`public/music.js`）
- ロビーの「🏠 ホームに戻る」でルームを抜けてタイトルへ

### 鬼の世界のルール

- マップは横10×縦7ブロックの街（毎回ランダム）。毎回 **赤鬼・青鬼・黒鬼** のどれかがボス鬼として現れ、開始時に表示される
- **見回り鬼**（紫）：視界（黄色い扇形）に入ると見つかる。笛を吹きながら追いかけてくる（攻撃はしない）
- 見つかると**ボス鬼に居場所が報告され**、ボス鬼が向かってくる。見回り鬼を倒すと伝達が途切れる
- **ボス鬼は歩きでは振り切れない**。ダッシュならギリギリ振り切れる。ダッシュを使い切ると、少し回復するまで「ぜぇぜぇ…」で走れない（スタミナはキャラの頭の上に表示）
- 見回り鬼を倒すと鬼玉を3〜5個、ボス鬼を倒すと**どデカい鬼玉**（赤鬼50個分・青鬼100個分・黒鬼150個分）を落とす
- 襖は、前で攻撃ボタンを長押ししたときだけ開く（ぶつかっただけでは出ない）。先に脱出した人は、残っている仲間を観戦できる（タップで切り替え）
- 全員が脱出するか倒れるか、時間切れになると、全員そろってガチャ画面へ
- 倒れた仲間の近くに3秒立つと復活させられる
- 左上のミニマップで、見回り鬼・ボス鬼・アイテム・襖・どデカい鬼玉の位置が見える。アイテムの種類は、画面に映ったときにわかる

### アイテム（1個まで持てる）

| アイテム | 効果 |
|---|---|
| ⚡ 電気トラップ | 足元に設置。ボス鬼が踏むと一定時間しびれる |
| 💣 爆弾 | 設置して3秒後に爆発。鬼に大ダメージ。範囲内の自分や仲間もダメージを受ける |
| 🤖 ロボットパンチ | 前方にパンチを飛ばし、鬼に中ダメージ |
| 🥤 スタミナム | 一定時間ダッシュし放題 |
| 🍙 おにぎり | 必ずHP全回復 |
| 👻 ジミーフィールド | 一定時間姿を消す。鬼に見つからず、追跡も切れる |

### 鬼ガチャ

脱出に成功した人だけが引けます。自分が集めた鬼玉が多いほど良い色のガチャ玉が出やすくなりますが、**必ず出るわけではありません**（ゲーム中は鬼玉の数だけ表示）。

| 集めた鬼玉 | 緑（C） | 青（B） | 赤（A） | 金（A/S） | 黒（S） |
|---|---|---|---|---|---|
| 0〜49 | 80% | 17% | 3% | - | - |
| 50〜99 | 30% | 55% | 12% | 3% | - |
| 100〜149 | 12% | 45% | 33% | 9% | 1% |
| 150〜199 | 4% | 22% | 50% | 19% | 5% |
| 200〜 | - | 15% | 30% | 33% | 22% |

金のガチャ玉は Aランク60%・Sランク40%。確率は `public/shared.js` の `BALL_ODDS` で変えられます。

出た妖怪はお友達になり、次からロビーで選べます。妖怪は全170体（C 52・B 50・A 40・S 28）。日本の妖怪のほか、西洋・北欧・ギリシャ・エジプト・中国・韓国・インド・中南米・アフリカ・北米・オセアニアの伝承の妖怪がいます。高ランクほどHP・攻撃力・速さが上がります。
お友達のデータはその端末のブラウザに保存されます。

### セーブ

お友達・遊んだ回数などは、その端末に自動で保存されます（ガチャの結果は、脱出が決まった時点で保存）。
タイトル画面の「💾 セーブ」で**引き継ぎコード**（`ONI1-` から始まる文字列）が表示されます。
別の端末やホーム画面のアプリで「コードを読み込む」に貼り付けると、データを移せます。

iPhoneでは、Safariとホーム画面に追加したアプリで保存場所が別々です。Safariで遊んだデータは、引き継ぎコードでアプリへ移してください。

### 妖怪のタイプ

| タイプ | 特徴 | 強攻撃 |
|---|---|---|
| ファイター | 近接・高火力 | ダッシュ斬り（無敵） |
| タンク | 高HP | じしん（周りにダメージ＋被ダメ軽減） |
| ヒーラー | 弾が味方に当たると回復 | 回復エリア |
| レンジャー | 遠距離射撃 | 3連ショット |

## ホーム画面に追加（アプリとして使う）

https://busters.onrender.com/ を開き、タイトル画面の「📲 ホーム画面に追加」を押します。

- **Android（Chrome）**：インストールの確認が出るので「インストール」
- **iPhone / iPad**：表示される案内のとおり、共有ボタン →「ホーム画面に追加」→「追加」

ホーム画面のアイコンから起動すると、アドレスバーなしの全画面・横向きで遊べます（iPhoneは向きの固定ができないため、横にして遊んでください）。
アプリ化は PWA（`public/manifest.json`、`public/sw.js`、`public/icons/`）で行っています。

**更新**：新しい版を公開すると、開いているアプリの上に「✨ 新しいバージョンがあります［今すぐ更新］」が出ます（プレイ中は出さず、タイトル・ロビー・結果画面で表示）。押すとその場で新しい版になり、「アップデートしました！」と変更点が表示されます。ホーム画面に追加し直す必要はありません。
サーバーの入れ替えでは、古いサーバーがプレイ中の試合を最後まで続けてから終了します（ロビーにいた人には「サーバーが更新されました」と表示）。Render の設定で、終了を待つ時間（Max Shutdown Delay）を最大の300秒にしておくと、試合の途中で切れません（`render.yaml` の `maxShutdownDelaySeconds`）。
変更点の文章は `public/whatsnew.json` に書きます。バージョンはサーバー起動時に画面ファイルの中身から自動で決まります（`/version`）。

## ゲームの絵

キャラ（妖怪170体・見回り鬼・ボス鬼3種）、アイテム6種、街の地面・屋根の絵はコードで描いてあります。最初の16体と鬼・アイテムは `tools/svg-art.js` の手描き、残りの妖怪は `public/yokai.js` の見た目指定（体の形・ツノ・羽・しっぽ・帽子・武器など）から `tools/yokai-gen.js` が組み合わせて描きます。
`npm run draw` で PNG にして `public/art/` に書き出します（API キー不要・無料）。ゲームは `public/art/manifest.json` を見て自動で読み込みます。

```bash
npm run draw                          # 全部書き出す
npm run draw -- --only=yokai/nekomata # 1体だけ
npm run draw -- --sheet=sheet.png     # 一覧画像も作る（確認用）
```

## 生成AIで絵を作る（Gemini / Nano Banana・有料）

キャラ（妖怪16体・見回り鬼・ボス鬼）、アイテム6種、タイトル背景、街の地面・屋根、アプリアイコンを、Gemini の画像生成でまとめて作れます。
できた絵は `public/art/` に保存され、ゲームが自動で読み込みます（無い絵は今までの図形で表示）。

```bash
npm install                      # 画像加工用の sharp も入ります
export GEMINI_API_KEY=...        # Google AI Studio で発行した API キー
npm run art                      # まだ無い絵を全部作る（約30枚）
npm run art -- --only=yokai/nekomata   # 1枚だけ作る（前方一致、カンマ区切り可）
npm run art -- --force           # 全部作り直す
npm run art -- --list            # 指示文（プロンプト）を確認する
npm run art -- --process-only    # tools/raw/ の元画像から切り抜きだけやり直す
```

- 指示文は `tools/art-prompts.js` で編集できます（絵柄は先頭の `STYLE` で全体共通）
- キャラは緑背景で作って自動で切り抜きます。最初に作った「ネコマタロウ」を絵柄の見本にして、ほかのキャラの絵柄をそろえます
- `icon/app` を作ると、ホーム画面用のアイコン一式（`public/icons/`）も作り直されます
- モデルは `GEMINI_IMAGE_MODEL` で変更できます（省略時 `gemini-2.5-flash-image`）

## 構成

- `server.js`：HTTP配信＋WebSocket。ルーム管理とゲームの計算はすべてサーバー側（1秒に30回計算、15回配信）。見回り鬼とボス鬼は道を探して（A*経路探索）追いかける
- `public/yokai.js`：妖怪170体の一覧（名前・ランク・タイプ・出身・見た目）
- `public/shared.js`：ランク・アイテム・ガチャの確率・ボス鬼のデータと、街の生成・当たり判定（サーバーとブラウザで共通）
- `public/title.js`：タイトル画面の背景（夜の鬼の街）とロゴをSVGで描画
- `public/game.js`：Canvas描画、ミニマップ、仮想スティック、ガチャ演出
- `tools/svg-art.js`, `tools/yokai-gen.js`, `tools/render-art.js`：コードで描いた絵と、PNG への書き出し
- `tools/gen-art.js`, `tools/art-prompts.js`：生成AIで絵を作るスクリプトと指示文（Gemini の請求先設定が必要）
- `public/index.html`, `style.css`：タイトル／ロビー／ガチャ／リザルト画面

テスト用の環境変数：`TIME_LIMIT`（制限時間を秒で変更）、`TEST_FUSUMA_NEAR=1`（襖を出発地点に置く）、`TEST_BOSS=red|blue|black`（ボス鬼を固定）、`NO_INTRO=1`（開始時の映像とカウントダウンを省く）
